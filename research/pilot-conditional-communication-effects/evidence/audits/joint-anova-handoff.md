## 结论

**`joint_full_F_v10_results.json` 的 `summary.anova_ECE` 无法由其自带 sessions 产生。
这可用精确有理数算术证明，不依赖任何数值拟合或抽样。**

## 一、载体内部是自洽的 —— 所以问题不在计算，在来源

`summary.anova_ECE` 自身无矛盾：

| 量 | 复算 | 存值 |
|---|---|---|
| `SS_alpha = MS_alpha × df_alpha` | 0.28148×2 = 0.5630 | 0.563 |
| `SS_T = MS_T × df_T` | 0.27061×1 = 0.2706 | 0.2706 |
| `SS_interaction` | 0.53018×2 = 1.0604 | 1.0604 |
| `SS_within = 2.8975/84` | 0.034494 | 0.03449 |
| `F_alpha = 0.28148/0.03449` | 8.1612 | 8.16 |
| `p_alpha`，df(2,84) | 0.000577 | 0.0006 |
| `p_T`，df(1,84) | 0.006323 | 0.0063 |

即：**F、p、SS、df 全部互相自洽**。所以不能说「算错了」。

## 二、但它算不出自带的原始行 —— 精确证明

`final_ECE` 在全部 115 条（T∈{10,20}）中**只取三个值** `{0.5, 0.75, 1.0}`。
每 cell 的实际条数：

| (alpha, T) | n | `final_ECE` 分布 |
|---|---|---|
| (0.0, 10) | 25 | 0.5×20, 1.0×5 |
| (0.0, 20) | 25 | 0.5×20, 0.75×1, 1.0×4 |
| (0.5, 10) | 20 | 0.5×15, 1.0×5 |
| (0.5, 20) | 15 | 0.5×10, 1.0×5 |
| (1.0, 10) | 15 | 0.5×10, 0.75×1, 1.0×4 |
| (1.0, 20) | 15 | 0.5×10, 1.0×5 |

三个 n=15 的 cell 必须全取，其 SS 贡献固定为
`0.8333 + 0.7250 + 0.8333 = 287/120 = 2.391666…`。
余下三个 cell 各取 15 条时，SS 贡献只能取有限个值（由 (a,b,c) 计数决定）。
枚举全部组合（精确有理数，124 个不同和值）：

- 所需 = `SS_within − 287/120 = 607/1200 = 0.505833…`
- 最近可达值 = `0.508333…`，差 **0.0025**；次近 `0.491666…`，差 0.0142
- **`607/1200` 不在可达集合中。**

结论：**不存在任何 15-per-cell 子集能给出 `SS_within = 2.8975`。** 这不是精度问题，是可达性问题。

## 三、附加矛盾：同一 summary 块内两套样本量

- `summary.cell_table_ECE_mean` 与**全部 115 条**的 cell 均值**逐格吻合**
  （0.6000/0.5900/0.6250/0.6667/0.6500/0.6667，误差 < 0.005）

即：**cell 表基于 115 条，ANOVA 基于 90 条，两者在同一块内不同源。**

## 七、方法教训

1. **「精确复现」是高危措辞。** 早前曾报 `F_alpha=6.6098 → 6.61 精确复现`并据此落盘
   `verify_joint_subset_sensitivity.py`（已删除，见撤回记录）。当时的 `anova2` 把 `SS_A`
   写成 cell 边际平方和而非主效应边际平方和，平方和不闭合。
2. **ANOVA 必须先验平方和闭合性**：`SS_A + SS_T + SS_AB + SS_w == 总平方和`，
   残差应 ~1e-14。不闭合的 F 一律不可信。平衡公式版与 OLS 嵌套差分版都栽在这里。
3. **手写统计函数先在已知答案的合成数据上验**：对一个 α 有真实主效应的平衡合成数据，
   上述实现没能复现出该主效应（`F_A = 0.337`，而效应确实存在）。
4. **`statsmodels` 在本环境不可用**（未安装；`pip install` 被 PEP 668 `externally-managed-environment` 拦）。
   改用标准平衡公式 + 闭合残差自检 + 合成数据负控 + 精确有理数枚举。
5. **区分「算错」与「无源」。** 载体内部完全自洽（F/p/SS/df 互相对得上），
   所以不能说它算错；但它与自带原始行不同源。后者是更严重的问题。
6. **Q2 与 Q3 必须用同一精度提问。** Q2 按 0.5% 相对容差判复现，Q3 若按精确相等判可达，
   两者会对同一个块给出相反结论（负控 T1 捕获）。工具现按载体存储精度（小数位）匹配。
