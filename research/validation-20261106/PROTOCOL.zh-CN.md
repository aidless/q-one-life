# AI 研究员能力验证：先导实验协议

冻结日期：2026-11-06。状态：先导，非论文级效度研究。

主论断：在固定预算下，系统可以从问题到训练、验证集选择、批评、
反驳实验、分析、草稿与独立重跑，留下真实可核验的记录。
辅助论断：错误、未知或伪造记录不会被当成已验证结果。

## 五个实验块

1. **来源审计**：真实 Git 对象与逐文件哈希包分开报告。仅有 HEAD 字符串
   不能证明 commit 存在。旧 closure 的字段一致性不能当成新实验关闭异议。
2. **真实闭环**：公开 breast-cancer、wine、diabetes 小数据集。
   两项复现、两项扩展、两项乱序标签负对照。训练/验证/测试 60/20/20，
   固定 seed 11/23/37。测试集在模型调用全部结束后只用于最终评估及独立复跑，
   不参与候选选择，不发给 agent。
3. **同预算比较**：single_agent / multi_agent / no_rebuttal；
   每条轨迹最多四次模型调用、三个候选训练，均使用同一模型。
   single/multi 首先是角色提示和分工路径的消融，不声称已经隔离全部多智能体机制。
   no_rebuttal 消费相同的批评与计划调用预算，但第三个训练保持初始候选；
   多智能体第三个训练采用反驳规划器的候选。
4. **故障注入**：输出删除、哈希变化、独立重跑不符、超时、网络失败、
   非有限指标、虚构执行、伪造 closure、陈旧 closure。正常对照必须放行。
   本组只评估新验证器，不得声称覆盖 RIDAR 的全部违规类型。
5. **外部校准和迁移**：获取真实论文与评审数据，按论文而非按 review 切分；
   验证标注尺度、历史稿件版本、同一论文重复/冲突评分。先冻结来源后评分。
   无独立人工标签时一律 pending，不会因负样本通过变成 calibrated。

## 数据及模型预算

- 三个内置公开数据集仅作为软件先导；可能存在预训练污染。
- 乱序标签是由真实特征构造的合成负对照，必须显式披露。
- 完整矩阵为 6 × 3 × 3 = 54 条轨迹，最多 216 次模型调用。
- 先做一任务一 seed 的三种变体（12 次调用）；若全失败，停止扩展并保留失败。
- 真实训练全部在 AMD 云实例，使用独立依赖目录、最多三个并发作业、
  每个估计器一个 CPU 线程。以 cgroup CPU 配额为资源依据，不用主机 nproc
  冒充实际分配核数。不训练/下载大模型，不购买新资源。
- 本地仅做下载、编排、模型网关转发、回执检查和短测试。
- 云端不能转发端口时，通过 SSH 文件信箱中转公开提示，
  不上传密钥或网关认证信息。

## 判据与负结果

- 闭环通过必须有真实模型调用、三个训练候选、测试未参与选择、独立重跑一致、
  全部输出哈希可核验；缺调用/解析失败/超时单列 inconclusive。
- 公开小数据的单次正增益不等于发现；乱序标签上出现表观增益不等于真信号。
- 只报告同 task/seed 配对的原始指标、实际调用/token/耗时；不把不同任务的
  balanced accuracy 与 R² 原始值平均成一个“科研质量分”。
- 不用这 54 条小先导轨迹推断顶会质量、新颖性或通用自主科研能力。
- 算法族和代码模板固定，暂不验证自主生成任意实验代码。
- 跨任务迁移只有通过未用于开发的外部任务后才能报告；当前六任务为开发先导。
- 不投稿、不发布、不提交/推送代码，不覆盖旧实验产物。

## 输出

suite.json 固定任务和预算；pilot-data/manifest.json 固定数据字节。
每条轨迹保存 split、四次调用、候选指标、分析、草稿、真实重跑与文件清单。
正式结果置于新 cloud-*/ 目录，失败尝试保留原目录。
数据获取及外部评测可用性见 datasets/ 与中文数据需求文档。
