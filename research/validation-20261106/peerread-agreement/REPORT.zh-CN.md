# PeerRead 评审一致性分析

日期：2026-11-07。结论：**PeerRead 人工推荐分目标本身噪声较大；这是任何
“rubric 校准”必须首先面对的上限。**

## 数据

- 来源：PeerRead 固定 revision 的 ICLR 2017 `reviews/*.json`。
- 去重规则：`(reviewer, DATE)` 唯一；`IS_META_REVIEW` 和 `IS_ANNOTATED=True`
  的匿名评审才计入；`RECOMMENDATION` 必须是整数。
- 论文数：66 篇有真实评审；其中 64 篇 ≥2 位评审。
- 评审行：**169 条**（不是 608；608 包含 histories 重复与元评审/非匿名）。

## 结果

| 量 | 值 |
|---|---:|
| 每篇评审数分布 | 1 篇×2 / 25 篇×2 / 39 篇×3 |
| 篇内平均分差 | 1.42 分 |
| 篇内中位分差 | 1 分 |
| 精确一致率（配对） | 30.3% |
| ±1 分内一致率 | 74.6% |
| ICC(1,1) | 0.124 |

## 含义

1. 人工推荐分是序数且只有 1–10，但同一论文的评审分歧通常 1 分，平均 1.42 分。
2. 精确一致只有 30%，说明“预测单个评审分”的上限很低。
3. ICC=0.124 意味着“论文间真实差异”只占很小一部分，大部分方差来自评审者噪声。
4. 因此即使 rubric 与某个“平均分”相关，也不等于能预测单评审；当前 28 篇样本
   更不足以支持论文级校准。

## 对前面结果的影响

- 24 篇 ρ=0.556、28 篇 ρ=0.213、6 篇 test ρ=0.79 都是在**有噪声目标**上的
  表现；这些数字不能直接当“校准精度”。
- 要评估 rubric 是否优于“随机预测”，需要先估计目标噪声上限，再做对比；
  目前没有这个基线。
