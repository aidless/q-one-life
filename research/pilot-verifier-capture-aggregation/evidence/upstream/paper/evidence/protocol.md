# PAPER6 Canonical Evidence Protocol (R16)

## Data sources

- **Main synthetic benchmark:** `evidence/main_results/benchmark_table.json`,
  `per_attack_table.json`, and `ensemble_sweep.json`; generated by the checked-in
  benchmark scripts with five seeds and 1,000 rounds per cell.
- **Synthetic pilot:** `evidence/pilot_results/summary_v2.json`; 4,000 trials
  per cell, used only for the pilot claim in the abstract.
- **Local real-model pilot:** `evidence/real_llm_results/summary.json` and
  `cells.json`; four local Ollama models, 20 questions, three seeds, two
  captured slots. This is descriptive and not a generalization test.

## Analysis rules

All headline values must be recomputed from per-seed or per-cell records. Means
are reported with the corresponding seed standard deviation; inferential claims
require an explicit test, effect size, confidence interval, and multiplicity
correction. No value from `main.tex.LLM_FABRICATED_DO_NOT_SUBMIT` is evidence.

## Reproducibility

The manifest at the paper root records SHA-256 hashes for the canonical package.
The exact Python version, dependency lock, model tags, prompts, and runtime
logs for the local pilot remain incomplete and are tracked as blockers.

## Evidence state

`verified` means the file exists and the value can be recomputed. `inconclusive`
means the evidence supports only a hedged statement. `blocked` means the claim
must not enter the manuscript.
