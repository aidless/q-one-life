# Closing landscape evidence protocol

- dataset: GSM8K/task prompts used by the TTRL scripts, license: follow the published task terms; no private data are included.
- Compute: real API and local smoke runs are separate artifacts; credentials are excluded. Each result file must record model endpoint, parser success rate, seed, and condition.
- The current real-API artifact shows confidence-parser degeneracy (CG/TEE gamma=0, H=1); it is retained as a failure diagnostic, not as scientific evidence of mitigation.
- The aggregate, checkpoint, final, and real result files are not interchangeable; provenance reconciliation is required before publication.
