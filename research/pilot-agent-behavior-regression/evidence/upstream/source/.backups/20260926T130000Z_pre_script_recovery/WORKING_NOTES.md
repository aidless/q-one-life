# PAPER35 Working Notes (R16)

The manuscript is now treated as a local-model behavioral heterogeneity study,
not a temporal-drift or frontier-model validation paper. Canonical evidence is
the full 1,200-cell run and its analysis JSON; smoke, pilot, and failed jobs are
kept separate. BDS is a token-distribution proxy and cannot be interpreted as
semantic disagreement without a convergent semantic audit.

Open questions: tokenizer/metric sensitivity, hierarchical uncertainty across
scenario categories, prospective validation, and whether the multi-agent chain
pilot reflects causal amplification.
