# PAPER35 Canonical Evidence Protocol

The canonical package is the 100-scenario suite under `data/scenarios/` and the
1,200-cell local-model run under `experiments/full_run/`. Four local Ollama
checkpoints are evaluated at temperature 0 with three seeds per scenario.

Dataset: the released synthetic behavioral regression suite generated by
`scripts/scenario_generator.py`, seed 20260711; license: project release terms
and upstream task licenses recorded in `README.md`.

The primary metric is BDS, a symmetric KL-style distance over whitespace-token
distributions with pooled top-K vocabulary and Laplace smoothing. Cross-seed
and cross-model comparisons are paired by scenario. The multi-agent chain,
smoke runs, and empty/error logs are auxiliary or pilot evidence and do not
support causal amplification or temporal-drift claims.

The local checkpoints are not calendar snapshots. Therefore this package does
not identify temporal drift or generalize to frontier APIs without new data.

Hardware: single CPU worker with Ollama local inference (no GPU required for
the analysis stage); runtime: approximately 1.7 hours for the 1,200-cell
generation run, as recorded in `experiments/full_run/_manifest.json`.
