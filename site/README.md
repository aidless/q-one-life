# Q-One Website

This directory is the static GitHub Pages source. It deliberately links only
to GitHub Releases and makes no download-availability claim before signed
installers exist.

Publication is a separate external gate:

1. A signed Beta or stable release must exist.
2. The relevant update channel and checksum manifest must be published.
3. The site workflow must be dispatched manually.
4. Real-hardware system requirements must be confirmed before adding them.

The page has no analytics, remote fonts, cookies, or third-party scripts.
