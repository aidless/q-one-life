BEFORE YOU START

几个直白的问题。

没有下载模型，还能用吗？

可以。目标、行动、反馈、备份和恢复都能由本地规则完成。

需要账号或订阅吗？

不需要。项目保持 MIT、免费、无账号、无云同步。

工作数据库是加密的吗？

不是实时数据库加密。工作库依赖操作系统文件权限；备份容器才单独加密。建议开启系统全盘加密。

Linux 如何更新？

AppImage 支持签名更新；deb 使用手动更新，并在应用内提示下载位置。
