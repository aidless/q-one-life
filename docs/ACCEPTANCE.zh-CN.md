# v0.2 验收记录

日期：2026-10-24。所有浏览器验收及模型连接测试使用明确标记的合成数据，位于独立临时目录，未读入个人真实记录。这里报告的是工程可用性，不是个人收益、模型准确率或概率校准研究。

## 自动检查

- q-one-core：12项，包括已有预测计分回归、替代选项结果排除、重复结算、状态校验、并发初始判断、时区与有限值。
- q-one-agent：7项，包括输出结构、未知选项、无效强度、字段白名单、远程确认、错误隐藏和Laya截断拒绝。HTTP使用MockTransport，Laya截断使用显式夹具。
- q-one-life：13项，包括完整人工流程、显式模型夹具、重启持久化、任务去重、失败后手动选择、预览绑定、跨站操作拒绝、密钥隐藏、三种指标方向、更正与时间窗口、来源检索、备份恢复、损坏拒绝、中断恢复和未完成创建的补录。

合计32项。前端脚本通过语法检查。应用测试和浏览器演练分别保留其证据边界，夹具不会被当成真实模型性能。

## 真实本地模型调用

| 路径 | 样本 | 结果 | 单次墙钟耗时 | 证据 |
|---|---|---|---|---|
| Ollama qwen3:8b | 一条合成二选一问题 | 有效JSON，选a，建议保存 | 35.032秒 | [原始回执](evidence/ollama-smoke-20261024.json) |
| Laya multilingual，CPU | 同类合成问题 | 选a，推荐强度0.2756；低强度及校准不足提示保留；输入未截断 | 76.557秒 | [原始回执](evidence/laya-smoke-20261024.json) |

耗时包括本次请求的模型加载与调用开销，只是单次观测，不能代表延迟分布或模型之间的公平性能对比。两次都没有填写行动成功概率，没有自动确认最终选择，也未计算准确率。Ollama回执含模型digest；Laya回执含请求权重revision、依赖版本、输入token信息及设备。

复现：先在独立数据目录启动本机服务，再运行 `python scripts/model_smoke.py --provider ollama --output /tmp/ollama-smoke.json` 或替换为 `laya`。此脚本会新建合成决策，不应连接日常个人数据空间。

云端兼容路径：协议和确认机制已由夹具测试，未配置真实服务密钥，未完成真实云端调用。Jev闭源服务未接入；本项目使用的是Laya和可替换的生成模型接口。

## 安装与持续集成

安装脚本提供仓库外运行环境，固定内部包提交，基础安装不下载Laya/PyTorch或模型权重。干净环境的安装、测试及启动结果记录在 [安装验收回执](evidence/package-acceptance.json)。最初pip路径遇到包CDN的TLS连接失败；保留证书验证，改用本机已有uv后完成安装，安装脚本优先uv、无uv时使用pip。

核心库与适配器的GitHub Python 3.10/3.12检查均已通过：

- [core检查](https://github.com/aidless/q-one-core/actions/runs/40081615967)
- [agent检查](https://github.com/aidless/q-one-agent/actions/runs/40081643639)

应用仓库的 Python 3.10/3.12 [自动检查已通过](https://github.com/aidless/q-one-life/actions/runs/40082366447)。各检查对应提交见 [远端回执](evidence/github-checks.json)，后续提交状态以 GitHub Actions 为准。

## 未完成与使用限制

没有长期真实个人试用、随机比较实验、个人校准、因果收益验证、私有权重训练或自动外部执行。没有多用户身份隔离和公网部署验收。资料使用词法检索、前部片段；Ollama长输入尚无完整token预算预检。

本版本完成的是一个可安装、可操作、可留存和复盘的个人系统。把它扩展为适用于所有人生领域的可靠决策模型，仍需分领域数据与验证。
