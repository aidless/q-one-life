# v0.3 自动推荐系统：使用与验收

日期：2026-10-24。此版本把主动推荐设为主要入口。用户保存目标后，系统自行生成下一步，省去先创建决策、填写备选项和逐条请求建议的步骤。

## 日常使用

1. 在“今日推荐”添加目标、完成标准、优先级与可选期限。
2. 保存后后台自动处理。首页先显示标为“规则建议”的行动，再自动展示本地模型生成或排序的结果。
3. 查看具体行动、预计分钟数、依据和来源，选择“采纳为今日重点”或“今天忽略”。
4. 在行动清单勾选完成。系统根据已完成的相关行动，继续推荐下一步；长期目标是否完成由用户确认。

每日预算默认为90分钟，可在设置中修改。它是用户可调整的计划参数，并非对真实空闲时间的测量。采纳只安排一个时间块，不替代实际执行，也不会自动勾选完成。已有任务被采纳时只聚焦原任务；新目标步骤生成独立任务，阶段变化后不会复用已完成的任务。

## 自动触发及资源边界

服务启动、成功写入目标/任务/观察等数据、以及跨日时检查更新。后台独立于网页，网页关闭时只要服务还运行就会继续。空闲每30秒检查一次；数据不变时缓存，默认6小时重评，失败后至少5分钟重试。模型任务共用一把锁，当前忙时继续提供规则建议。

输入变化或模型配置变化后，旧推理结果不得覆盖最新状态。推荐内容变化后，旧版本的采纳请求会被拒绝。关闭自动推荐会停止新模型调用；已发给本机模型服务的推理可能继续完成，返回后会检查当前状态。

Ollama生成有界候选对应的具体步骤。Laya对已有候选做类型化排序，不生成独立解释。自动调用仅允许本机Ollama或Laya，不能借用远程地址自动上传目标；原有远程手动接口继续要求预览确认。

每轮最多包含前4个活跃目标、6个待办候选、8个完成记录、6项近期指标摘要、2段资料片段，最终最多8个候选。模型最多返回3项，必须引用现有候选ID、保持唯一，并满足剩余分钟数预算。已有任务名称保留原文，新目标步骤可由模型细化。输入过长或格式无效时保留有来源标记的规则建议。

目标默认按优先级和期限排序；待办先按期限、再按任务优先级排序。模型仍可能产生不合适的行动或依据，需要人工审阅。这里没有个人收益提升、因果判断或推荐成功率承诺。

## 数据与恢复

新增goals和suggestions两类记录，当前推荐、反馈状态、来源和关联任务保存在本地。跨日覆盖后的忽略历史目前不另行归档，也不据此训练个人偏好模型。模型调用记录保存有界输入快照、结构化输出、输入摘要、模型来源、耗时与使用信息；不会包含云端密钥或原始观察备注。

私有备份格式升级为q-one-backup-v2，包含目标和建议；仍能读取旧q-one-backup-v1并为空缺的新表补空。公开摘要继续不包含目标、推荐正文和模型输入。包含个人资料的完整备份应保存在私有位置。

日期使用服务机器的本地日期。当前没有日历读取、跨设备同步或OS开机自启；运行入口与停止方式仍为README中的脚本和Ctrl+C。
