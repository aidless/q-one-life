# Q-One 科研量化层

日期：2026-10-27

这层把“万物量化”应用到科研生产本身。目标不是给论文生成一个不可解释的总分，而是把论文的状态、证据、实验、评审和投稿包变成可观察、可复算、可追溯的记录。

## 1. 对象

| 对象 | 含义 | 最小标识 |
|---|---|---|
| `PaperProject` | 一篇论文的唯一正本 | `paper_id`、根目录、主稿哈希 |
| `Claim` | 摘要、正文、图表或结论中的一条可判断陈述 | `claim_id`、正文位置、证据引用、状态 |
| `Evidence` | 支持或反驳论断的文件、字段或外部记录 | 来源、字节哈希、字段、获取时间 |
| `Experiment` | 一次真实执行 | 环境、代码提交、输入哈希、命令、输出、退出状态 |
| `Review` | 对方法、统计、引用、复现或表达的独立检查 | 严重度、证据、状态、责任人 |
| `Artifact` | 值得复用的中间结果、图表、表格或数据 | 版本、输入、命令、文件哈希 |
| `Package` | 可提交的论文包 | 主稿、PDF、BibTeX、图表、许可证、总哈希 |
| `Submission` | 外部平台动作和回执 | 平台、版本、时间、状态、URL、回执哈希 |

文件存在不等于实验执行，实验执行不等于科学结论，外部发布也不等于录用或获奖。

## 2. 量化规则

每个测量必须声明：

- `definition`：到底在数什么，不能只写“质量”。
- `unit`：个数、比例、秒、字节、版本号或人工等级。
- `direction`：越高越好、越低越好、接近目标或仅分类。
- `window`：时间范围或数据窗口。
- `source`：文件、字段、运行回执或外部 API。
- `missing_policy`：缺失、冲突和失败如何显示。
- `aggregation`：是否聚合、如何聚合、是否允许比较。

系统不生成全局论文分数。常用可计算量分开保留：

- `claim_evidence_coverage`：有合格证据引用的论断数 / 已登记论断数。
- `claim_recomputation_coverage`：有可运行复算方法的数字论断数 / 数字论断数。
- `experiment_reproduction_coverage`：可复跑并哈希一致的必需实验数 / 必需实验数。
- `citation_verification_coverage`：已解析并匹配元数据的引用数 / 引用总数。
- `unresolved_critical`：未解决 Critical 缺陷数。
- `unresolved_major`：未解决 Major 缺陷数。
- `package_completeness`：投稿清单中已通过的条目 / 适用条目。

这些量只在分母和窗口明确时显示。分母未知时值为 `unknown`，不是 0。

## 3. 状态

证据状态：

- `verified`：来源、字段和复算均通过。
- `candidate`：来源存在，但尚未完成独立复算或封存。
- `inconclusive`：当前证据不足以支持强断言。
- `blocked`：来源污染、缺失或与当前正文不一致。
- `unknown`：尚未检查。

论文状态：

- `planning`
- `evidence_review`
- `experiment_pending`
- `revision`
- `review_pending`
- `package_ready`
- `prepared`
- `submitted`
- `withdrawn`
- `archived`

论文状态由门禁结果决定，不由单一模型评分决定。

## 4. 断言门

一条论断进入强断言正文前必须满足：

1. 有稳定的 `claim_id`，摘要和结论也登记。
2. 每个数字指向证据文件、字段和复算方法。
3. 证据文件已记录 SHA-256。
4. `inconclusive` 只能使用 hedging 语言，并写明升级条件。
5. `blocked` 不得出现在正文、图表、摘要或结论。
6. 人工作者身份、利益冲突、许可证和外部发布授权不得由模型推断。

## 5. 论文组合

论文组合不是“PDF 文件列表”。它是经过内容哈希归并的正本项目集合：

- 相同主稿字节的备份、release、submission 和旧复制归入一个重复组。
- 重复组只选择一个规范项目，其他副本保留路径和哈希。
- 旧稿被合并或归档时保留历史，不删除证据。
- 每个项目必须有唯一状态和下一步，可以为 `unknown`，但不能消失于清单。

## 6. 自主边界

Q-One 可以自动：

- 扫描项目、提取标题、计算哈希、聚类重复版本。
- 生成 Claim Ledger、检查缺失字段和引用。
- 运行被授权的本地复算、编译和测试。
- 起草、改写、生成图表和列出阻塞。

Q-One 不可以自动：

- 编造实验、引用、作者、许可证或外部回执。
- 将模型评审当作录用概率。
- 消耗付费或 GPU 资源而不经授权。
- 登录账号、上传论文或发布公开版本而不经授权。
